# My Algorithm

This file *is* my recommendation algorithm. The sweep ranks everything the platforms serve
against what's written here, keeps only what scores well, and hunts for more of it. I control
my feed by editing this file (or telling the sweep "more X / less Y", which it folds back in
here and logs in [[feedback-log.md]]). Git tracks how my algorithm evolves.

The sweep **refuses to run while the Interests section is empty** — fill it in first.
